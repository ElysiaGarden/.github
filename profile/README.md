# Elysia Garden

Home of **Elysia**, a 1v1 Rocket League bot for RLBot v5 trained with reinforcement learning (PPO self-play in
RocketSim).

| Repository | Contents |
|---|---|
| `elysia-training` | Training code: C++ and Python trainers, training loop, evaluation, live bot |
| `Elysia` | The ready-to-run bot, one folder per version |
| `elysia-champions` | Every promoted version and the training status table |
| `elysia-checkpoints` | Backups of older checkpoints |
| `elysia-matches` | Reports of real RLBot matches |
| `elysia-status` | Live training status |
| `elysia-docs` | Notes, reviews and plans |
| `elysia-lab` | Experiments outside the training loop |

Every repository except this one is private.
